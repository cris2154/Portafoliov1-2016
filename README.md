# Portafolio v1 - 2016

Proyecto básico de Portafolio Personal desarrollado para el segundo examen de Programación Web Básica (2016).

## Tecnologías utilizadas
- **HTML5** básico (estructura por secciones)
- **CSS3** básico (color morado principal, medidas con `vh`, diseño responsivo sencillo)
- **JavaScript** básico (menú móvil, alerta de descarga de CV y validación de formulario)

## Secciones
1. Inicio (Hero `100vh`)
2. Sobre Mí y Especialidad
3. Servicios
4. Portafolio de Proyectos (con enlaces interactivos a proyectos desplegados en Netlify y GitHub)
5. Testimonios
6. Contacto (con datos personales y formulario prellenado)
